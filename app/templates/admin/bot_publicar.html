Funcionamento

Use o mesmo serviço WhatsApp já conectado. O comando funciona no grupo padrão do WhatsApp.

Fluxo no grupo
  1. Digite /publicar.
  2. Envie a imagem da matéria.
  3. Envie o título.
  4. Envie o texto completo.
  5. O bot publica e responde com o link.
Quando desligado, o endpoint recusa novas publicações.
Esse token protege a publicação. O serviço WhatsApp usa esse valor para chamar o site.

Variáveis do serviço WhatsApp

Se o bot não responder ao comando, coloque estes valores no Railway do repositório WhatsApp.

Copie para o serviço Node/Baileys
BOT_PUBLISH_ENABLED=1
BOT_PUBLISH_API_URL={{ api_url }}
BOT_PUBLISH_TOKEN={{ cfg.token }}
O envio automático de matérias para o WhatsApp continua funcionando separado. Este bot só cria matérias quando alguém digita /publicar no grupo.
